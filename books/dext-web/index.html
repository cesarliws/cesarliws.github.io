A Nova Era do Delphi Web

Por que este livro é um divisor de águas?

Uma obra escrita para levar o ecossistema Delphi ao estado da arte no desenvolvimento de backends corporativos, microsserviços e computação em nuvem.

Por quase duas décadas, desenvolver para a web em Delphi significou lutar contra paradigmas herdados do desktop: estado em memória, acoplamento excessivo com componentes visuais e falta de suporte nativo aos padrões arquiteturais da nuvem moderna.

Desenvolvimento Web Profissional com Delphi e Dext Framework muda esse jogo de forma definitiva. Com base no Dext Framework — moderno, modular e inspirado no que há de mais elegante em ecossistemas como ASP.NET Core e Spring — este livro ensina passo a passo como projetar e construir aplicações seguras, escaláveis, testáveis e preparadas para rodar nativamente em Linux, Docker e Kubernetes.

Aqui você não encontrará exemplos teóricos vazios: cada conceito é validado com código fortemente tipado, testes automatizados e integração com a era dos Agentes Autônomos de Inteligência Artificial.

Estudo de Caso Prático

O Projeto Real: Dext Faturamento

Você constrói um ecossistema corporativo financeiro completo, evoluindo a cada capítulo através de 5 Laboratórios Integradores.

Laboratório 1

Primeira API Completa de Clientes

Construção do módulo de gestão de clientes com Minimal APIs, DTOs tipados, validação fluente Fail-Fast, middleware de tratamento de exceções e asserções automatizadas.

Laboratório 2

O Motor de Persistência e Consultas Avançadas

Implementação do módulo de cobrança com Dext Entity ORM, Unit of Work, Smart Properties e consultas dinâmicas reutilizáveis com o Specification Pattern.

Laboratório 3

Plataforma Multi-Tenant Segura com CQRS e Rate Limiting

Isolamento estrito de dados entre empresas clientes, autenticação com tokens criptográficos JWT, controle de autorização por Claims e proteção contra abusos com Rate Limiting.

Laboratório 4

Microsserviço Observável Conteinerizado em Docker

Empacotamento da aplicação em imagem Linux minimalista, instrumentação com Health Checks, métricas Prometheus e documentação viva e interativa com Swagger/OpenAPI.

Laboratório 5

Aplicação Enterprise Multi-Canal (HTMX, gRPC, Testes e IA)

Consolidação do sistema com interface SSR hiper-rápida em HTMX, canal de alta velocidade binário gRPC, suíte completa de testes unitários/integração e exposição de ferramentas para Agentes de IA.

CustomerEndpoints.pas (Minimal API) 
procedure MapCustomerEndpoints(const App: IWebApplication);
begin
  App.MapGet('/api/customers/{id:int}',
    function(
      [FromRoute] Id: Integer;
      [FromServices] Repo: ICustomerRepository
    ): IResult
    begin
      var Customer := Repo.FindById(Id);
      if Customer = nil then
        Exit(Results.NotFound);

      Result := Results.Ok(Customer);
    end);
end;
